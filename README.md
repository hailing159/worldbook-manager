# 世界书管理器（手机端）

## 安装
1. 解压 `worldbook-manager.zip`。
2. 将 `worldbook-manager` 文件夹放入 `SillyTavern/public/scripts/extensions/third-party/`。
3. 回到酒馆强制刷新页面。

## 功能
- 展示世界书列表，点书名/箭头展开查看条目。
- 左侧复选框尝试同步酒馆原生 `#world_info` 全局世界书选择；已启用会勾选。
- 列表区域限制高度，可在内部滚动。
- 批量管理：勾选要下载或删除的世界书。
- 批量上传 JSON 世界书文件；同名文件可选择覆盖或跳过。
- 页面内运行日志，便于手机端反馈问题。

## 重要说明
本插件尚未在真实酒馆实例验证。不同 SillyTavern 版本的世界书 API 路由、响应格式和全局选择框可能有差异。首次安装建议先用一本文档测试全局开关、单本下载、单本上传；批量删除前务必备份。批量上传以酒馆导出的单本世界书 JSON 为准。
